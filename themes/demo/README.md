# Clear - Modular Multipurpose Octobercms Theme with powerful Theme Settings and an Page Builder system.

Features
--------
* Responsive Design
* High Overall Quality
* Lightweight code
* Scroll Animations
* Bootstrap 4 Carousel Sliders
* Bootstrap 4 Tabs
* Owl Carousel 2 with Images &amp; Videos
* Portfolio with Images &amp; Videos and Magnific Popup Feature
* Custom Rich Metadata
* Subscription Feature Using Railab Mailchimp Plugin
* Account Feature using Railab User plugin
* Blog Feature using Railab Blog plugin
* Blog post auto creates Carousel for Uploaded Featured Images
* 26 Premade Section Blocks to choose
* Blog with Tags, Search, Gallery and Comments
* Contact Us page
* Google Map that can Show your Spot only by Entering your Address!
* CRUD Generator - Page builder system for easy page creation. You can create Carousels, Tabs, Pricing Tables, Galleries, Progress Bars, Services, Features, Contact, Subscribe, Maps and more!

Theme settings
---------------------
* Site Info and Locale 
* Google fonts , FontAwesome icon Fonts and Linear Icon Fonts
* Brand selector, Text or Logo. Upload your Logo
* Favicon selector. Upload your Favicon
* Pageheader Image selector. Upload your Pageheader Image
* Enable Disqus Comments
* Enable Social Links
* Container &amp; Fluid Container option with Container width selector
* Layout Settings, Blog Layout, Blog Post Layout with sidebar and main area width settings
* Blog special settings with 2 blog post style types. Blog Next &amp; Prev Blog Post Navigation, Post Gallery, Similar Posts, Comments. Enable/Disable Sidebar Widgets.
* 9 Pre-Built Color Schemes that can be Switched, and a Custom color style option that give you Unlimited Theme Color Possibilities
* Animate CSS, AOS JS, Normalize CSS, Smooth Scroll, Sticky Menu, Transparent Header, Scroll To Top, Page Loader, Parallax Effect, Particles Effect Addons
* Topbar Options with Account option, Language selector and Call Us number
* Footer Options with Contact Info Fields and Subscribe text.
* Add your own Social media with your own Icons
* Add your own Images Gallery
* Custom CSS , Custom JS and Google Analytics

Enhancements
--------------
* CRUD Generator System that help you Create, Modify, Update or Delete Fields inside Blocks. A Page Builder system with 26 Premade Blocks that lets you create Unlimited Custom Pages.
* Blog Featured Images Enhancement. If you upload more than one Images to a Blog Post, an image Carousel Automatically Created on Post Image place. One other Carousel is Created after the Post.
* Special Layout Settings for your Blog and Blog Post Pages. You can choose Right Sidebar, Left Sidebar or No Sidebar. You can choose Main Area and Sidebar Width.
* Container Type. You can choose Container or Fluid Container with your own container width.
* Special Blog Post Settings. Choose between 2 Blog Post Types. Enable Transparent Header on Post. Enable Next &amp; Prev Post Navigation, Gallery, Similar Posts and Comments. You Can Enable or Disable Sidebar Widgets.
* Reorganized folder structure for OctoberCMS
* Additional Rich Metadata Included.
* Copyright year displayed with Variable
