Données personnelles

Le site étant une démonstration, merci de ne pas utiliser le formulaire de contact pour transmettre de vraies informations personnelles. Si vous le faites malgré tout, voici comment ces données sont traitées.

Données collectées

Le formulaire de contact recueille les informations que vous saisissez : nom, adresse e-mail, téléphone (facultatif), type de projet, budget, délai, description du projet et fichiers joints éventuels. L'adresse IP de l'expéditeur est également enregistrée afin de limiter les abus.

Finalité et base légale

Ces données servent uniquement à démontrer le fonctionnement du formulaire et, le cas échéant, à vous répondre. Leur traitement repose sur votre consentement, recueilli par la case à cocher du formulaire. Elles ne sont jamais utilisées à des fins commerciales, ni cédées ou vendues à des tiers.

Destinataires et conservation

Les demandes sont transmises par e-mail à l'éditeur du site et enregistrées dans la base de données du site, chez l'hébergeur mentionné ci-dessus. Un e-mail d'accusé de réception est envoyé à l'adresse saisie. Les demandes sont supprimées au plus tard 3 mois après leur réception.
